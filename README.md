# Media Manager

A professional social media planning and publishing platform designed for modern marketing teams.

## Features

- **Campaign Planning** - Organize your social strategy with products and campaigns
- **Multi-Platform Composer** - Create once, optimize for each platform automatically
- **Smart Scheduling** - Visual calendar with intelligent scheduling
- **Media Vault** - Centralized asset management
- **Analytics** - Track performance across all channels
- **MCP Integration** - Agent-accessible API for automation
- **TaskJoe Integration** - Seamless task management

## Getting Started

```bash
npm install
npm run dev
```

Visit http://localhost:3000

## Press Kit

A complete press kit is available at `/press` including:
- Brand assets (logos, wordmarks, social cards)
- Product screenshots
- Fact sheet
- Downloadable press kit zip

See [PRESS_KIT_README.md](./PRESS_KIT_README.md) for details.

## Development

```bash
npm run dev          # Start development server
npm run build        # Build for production
npm run lint         # Run ESLint
npm run typecheck    # Type check with TypeScript
npm run test         # Run tests
```

## Configuration

- `brand.config.json` - Product branding and information
- `press.config.json` - Press kit settings (URLs, contact, assets)
